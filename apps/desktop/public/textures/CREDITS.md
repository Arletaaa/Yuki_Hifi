## 规则

1. 只接受 **CC0 / 公有领域** 或 **CC-BY（可署名）**；不接受 NC / ND / 来源不明。
2. 贴图入库前压到 1024 以内、单张 ≤ 500KB（当前 1K 原图最大 1.7MB，后续可压）。
3. 模型入库前确认面数 ≤ 5k、贴图内嵌（`.glb`）。
4. CC-BY 素材必须在「关于」页可见，且链接可点。
