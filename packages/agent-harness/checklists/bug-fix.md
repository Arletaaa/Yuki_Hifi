# Bug Fix Checklist

## 诊断

- 是否通过复现步骤确认了 bug 表现。
- 是否通过日志、状态快照或断点确认根因。
- 是否排除了本次变更范围外的无关因素。

## 修复

- 是否以最小改动修复根因。
- 是否避免引入真实音频解码、新舞台或新架构。
- 是否补充或更新了单元测试，覆盖回归路径。
- 是否保持 TypeScript strict mode 通过。
- 是否避免 `any`；如必须使用，是否有就近注释解释。

## 验证

- `pnpm typecheck` 是否通过。
- `pnpm test` 是否通过。
- `npm run build` 是否通过。
- 修复后是否再次验证复现步骤不再出现 bug。
- 修复是否没有破坏相邻功能（播放、切歌、进度、队列）。
