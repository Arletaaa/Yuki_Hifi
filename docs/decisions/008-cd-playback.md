# ADR 008: CD 内播放与三种播放模式

## 状态

已接受（2026-10-30）。替代 ADR 006 中“设置里选择播放模式”的交互位置，并扩展播放语义。

## 背景

v1.0 已收敛为单排 CD 货架 + CD 盒 + 唱片机。此前播放只有“当前曲目”，没有 CD 内上一首/下一首；播放模式只有“循环播放 / 播完即停”，且放在设置浮层里。多曲 CD 已经通过 `GalleryGroup.trackIds` 存在，但播放链路只用了第一首。

## 决策

### 1. 详情播放条

- 播放条只在唱片机开始播放后出现，替换详情页左下角专辑 caption。
- 内容：状态、曲名、艺术家/专辑、可拖动进度、格式/采样率/位深/质量、上一首/播放/下一首、顺序/循环/随机。
- 播放键与唱片机 Start/Stop 共用同一段逻辑（`TurntableBridge.toggleStartStop`），包括按钮下压与电机状态。
- 进度拖动通过 `seekTo` 写入 store，由 `useAudioPlayback` 同步到 `HTMLAudioElement.currentTime`。

### 2. 队列等于当前 CD

- 从唱片机开始播放时，`playTracks(groupTracks)` 把 `queue` 设为这张 CD 的曲目，顺序来自 `GalleryGroup.trackIds`。
- 上一首/下一首只在当前 CD 内移动，不跨 CD。
- 单曲 CD 也显示完整按钮；顺序模式下“下一首”重播当前曲，循环模式回绕。

### 3. 三种模式

| 模式 | 曲目结束 | 手动上一首/下一首 |
| --- | --- | --- |
| 顺序 `sequential` | 播到 CD 最后一首停止 | 到边界停止/重播当前 |
| 循环 `loop` | 回到 CD 第一首 | 首尾回绕 |
| 随机 `shuffle` | 随机下一首 | 随机切换，避开当前曲 |

- 旧设置迁移：`stop` → `sequential`，`repeat-one` → `loop`。
- 设置浮层不再提供播放模式；模式只在详情播放条切换。

### 4. 播放键语义

“播放”不是独立于唱片机的第二套控制器，而是详情条对唱片机 Start/Stop 的远程触发：

- 播放中按下：停转 + 暂停；
- 暂停中按下：起转 + 继续；
- 唱片机按钮与详情条播放键始终同步。

## 后果

- 设置浮层少一块，详情条承担传输控制；详情条必须保持轻量、不遮挡 3D。
- 播放模式从“单曲循环/停”变成“整张 CD 的顺序/循环/随机”，是语义变化，需要迁移旧设置。
- 单曲 CD 的下一首在顺序模式下重播当前曲，保证按钮不失效。
- 播放条只在唱臂落下后出现；抬起唱臂会隐藏播放条，避免出现“播放键无法恢复声音”的状态。
