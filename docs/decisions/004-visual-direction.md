# ADR 004: 视觉方向「夜空唱片室」与自定义背景边界

## 状态

已接受（2026-10-24）。

## 背景

原界面是浅色糖果渐变玻璃风（粉→蓝→薄荷、28px 大圆角、发光按钮、浮动面板），与 design-language 里"安静、克制、稳定的桌面音乐工具"的定位互相矛盾，也出现了遮挡内容的实际问题。

用户要求：二次元风格、背景可自定义，使用 frontend-design 方法论重做，同时不违反「主播放器页面不得出现右侧舞台、角色舞台、Live2D、MV、动态视觉舞台」的硬约束。

## 决策

### 1. 气质

「夜空唱片室」：深靛蓝夜色底 + 樱花粉信号色 + 少量冷青光；材质是磨砂玻璃与细描边；气质是深夜独自听歌的安静感，不是游戏 HUD，也不是角色看板。

### 2. 二次元表达只走三条克制路线

1. **排版**：标题/曲名使用有笔触或几何个性的展示字体（拉丁为主），日文小字注音风格作为装饰性副标签。
2. **色彩与光**：樱花粉只用于当前播放、选中态与信号强调，面积不超过一屏的 10%；青色只用于"信号/链路"类信息。
3. **纹样**：封面占位使用唱片纹/磁带几何图形与柔光，不使用人物插画。

### 3. 自定义背景的边界

| 允许 | 说明 |
| --- | --- |
| 用户选择的静态图片作为整窗壁纸 | 通过主进程选择文件，受控媒体协议读取，路径持久化 |
| 壁纸暗化、模糊、颗粒噪点层 | 用于保证前景文字对比度 |
| 内置程序化渐变背景 | 未选择壁纸时的默认，无版权风险 |
| 可随时关闭/换回默认 | 设置页开关 |

| 禁止 | 原因 |
| --- | --- |
| 角色立绘舞台、Live2D、看板娘 | 硬约束 |
| 视频/MV/动态壁纸、按时序变化的舞台 | 硬约束（"动态视觉舞台"） |
| 壁纸压过前景对比度、遮挡控件 | 可读性优先，壁纸层永远在内容层之下且不可点击 |

### 4. 组件与动效

- 圆角收敛到 6 / 14 / 999 三档，阴影只保留一层柔和投影 + 1px 描边，禁止发光按钮。
- 动效时长 160–220ms，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`；`prefers-reduced-motion` 或设置项开启时全部降级为瞬时。
- 播放中的视觉反馈默认为静止封面 + 极轻的光晕；唱片旋转属于可关闭选项，默认关闭。

## 影响

- 需要重写 tokens、样式层与全部组件（现有 `player.css` / `theme.css` 基本不保留）。
- 需要新增两个主进程能力：背景图片选择（含白名单）与设置读写。
- 自定义背景属于"主题资产层"，与 design-language 的分层一致，不构成新舞台，需在评审时按上表检查。
