# ADR-006 曲库托管、场景预设与搜索飞行

状态：已确认（2026-10-26）
关联：[005-scene-gallery](005-scene-gallery.md)、[003-v1-scope](003-v1-scope.md)

## 决策 1：曲库由软件托管（复制入库）

**决定**：导入 = 复制。用户选择的单曲、多选的多个文件、或整个文件夹里**受支持格式**的音频，都复制到 `userData/library/` 下统一管理；原文件不动。

- 支持格式：`flac` / `wav` / `mp3` / `m4a` / `ogg`（与现有扫描器一致）。
- 去重：复制前比对 `(文件大小, 时长, 前 256KB 的 SHA-1)`；命中已有记录则跳过并提示"已存在"。
- 不复制封面外的其他附加文件；封面在解析阶段提取到 `userData/covers/`。
- 目录结构：`userData/library/<artist>/<album>/<title>.<ext>`（非法字符替换为 `_`）。

**理由**：托管后"重命名 / 设封面 / 删除"都只操作副本，安全可逆；也避免用户移动原文件后曲库失效。

**代价**：占用磁盘（与源文件等量）。因此**只导入受支持格式**，不复制图片、日志、压缩包等。

## 决策 2：场景预设替代深/浅主题

**决定**：主题不再是 `dark | light`，而是一组场景预设：

| 维度 | 选项（可扩展） |
| --- | --- |
| 台面 | 木纹横向 / 木纹竖向 / 深胡桃 / 浅橡木 |
| 墙面 | 织物 009 / 织物 028 / 素色 / 渐变 |
| 剪影 | 无 / 树叶 / 百叶窗 / 圆孔光斑 |
| 光效 | 晨光斜射 / 夜色冷光 / 顶灯聚光 |

- 选择器形态：**材质球**（球体套用该材质，实时渲染），当前项用**绿色圆环**框选。
- 壁纸（自定义图片）设置项**删除**，并入场景预设。
- 存储：`settings.json` 增加 `scenePreset: { table, wall, silhouette, light }`。

## 决策 3：搜索 = 近似匹配 + 相机飞行

**决定**：

- 顶部搜索框输入 → 近似匹配（标题/艺术家/专辑，忽略大小写与全半角，支持子串与简单拼写容差）。
- 匹配结果在搜索框下方以浮层列出（曲目名 + 所属专辑），最多 8 条。
- 点击某条 → **相机飞行到该 CD**：两段式动画（先抬升并淡出 180ms，再滑行到目标 320ms），落位后该 CD 高亮并轻推向前。
- 不做瞬时跳转；飞行期间禁用拖拽输入。

## 决策 4：管理音乐（针对副本）

| 操作 | 行为 |
| --- | --- |
| 排序 | 前端排序（标题 / 艺术家 / 时长 / 导入时间） |
| 重命名 | 修改副本文件名与标签，写回 `settings.json` 的覆盖表 |
| 设置封面 | 写入 `userData/covers/<id>.jpg` 覆盖表 |
| 删除 | 删除副本文件 + 从曲库移除（二次确认） |

## 实施切片

1. **主界面**：画廊为唯一视图；顶部搜索框；右下设置按钮；删除 rail / player-bar / 列表页 / 队列页。
2. **设置浮层**：毛玻璃面板；场景预设材质球；音量；关于（CC-BY 署名）。
3. **导入与托管**：`library:import-files` / `library:import-folder` / `library:select-files` IPC；去重；进度反馈。
4. **管理音乐 + 搜索飞行 + 播放界面音量环**。
5. **清理与门禁**：删除废弃组件/样式、更新文档、`typecheck` + `test` + `build`。
