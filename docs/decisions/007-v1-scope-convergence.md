# ADR 007: v1.0 收敛为货架 + CD 播放器

## 状态

已接受（2026-10-30）。收敛 [ADR 003](003-v1-scope.md) 的 v1.0 范围，并取代 [ADR 005](005-scene-gallery.md) 中与长廊 / 收藏 / 列表降级相关的 v1.0 要求；ADR 005 的 3D 场景约束与判定标准仍然有效。

## 背景

v1.0 实现已经从“CD 长廊 + 播放台”收敛为“单排货架 + CD 盒 + 唱片机”：

- 画廊是单排货架，同时可见 7 张，没有 Bay 生长与跨 Bay 移动；
- 旧列表页、队列页、播放栏已删除，播放由唱片机唱臂触发；
- 收藏只有 store / 持久化，没有入口与外观；
- 播放进度、seek、格式 / 采样率 / 位深展示随旧播放栏一起消失。

继续把这些条目当作 v1.0 验收项，会让文档与实现长期不一致，也会把交付拖进大改。需要一次性把范围定死。

## 决策

### 1. 画廊固定为单排货架

v1.0 的唯一主视图是单排 CD 货架。长廊、Bay 生长、跨 Bay 移动、双击回当前 Bay 都移出 v1.0，放入 v1.1+ backlog，后续另开 ADR 再评估。

3D 场景的合法性标准不变：每个 3D 元素必须对应真实专辑或真实播放状态（ADR 005）。

### 2. 删除收藏需求

v1.0 不提供收藏，也不做金边 / 微光 / 列表 ★。现有 `favorites` store、`settings.json` 字段与单测作为死代码在 P1 清理；读取旧设置时忽略该字段即可，无需迁移。

### 3. 降级不作为 v1.0 门禁

不要求列表视图、无 WebGL 降级、低帧率自动降级。保留基础的键盘操作与 ARIA 标注；如果后续成本很低再补，不阻塞交付。

### 4. 进度与参数展示迁入 CD 详情 UI

不恢复旧播放栏。v1.0 在 CD 详情场景内新增一条轻量信息条：

- 当前曲目（标题 / 艺术家）；
- 播放进度（当前时间 / 总时长），支持点击或拖动 seek；
- 真实格式 / 采样率 / 位深 / 质量；读不到时显示 `—`，不展示 mock 数据；
- 控制区不遮挡 3D 拖拽与唱片机操作。

数据仍来自 `currentTrack`、`positionSeconds`、`durationSeconds`；seek 需要补一条从 UI 到 `HTMLAudioElement.currentTime` 的通道。

### 5. 原 MVP 标注取消

[MVP 基线](../product/mvp.md) 与 [场景长廊规格](../product/scene-gallery.md) 标记为“已取消”，保留作历史。与本文冲突的队列、播放台、三档播放模式、收藏、长廊、列表降级条款不再作为 v1.0 验收依据。

## 后果

- v1.0 的剩余交付集中到：门禁复跑、Windows portable 打包与装包冒烟、CD 详情信息条、基础收尾。
- 长廊 / Bay、收藏、列表降级、队列页、旧播放栏都进入 backlog 或 v1.1+，不再占用 v1.0 工期。
- 文档需要同步：roadmap、next-steps、MVP、scene-gallery、ADR 003/005/006、README、handoff。
- 风险：详情信息条可能遮挡场景；先在 1024×680 与 1440×900 两档验证，控制区只让可交互元素接收指针事件。
