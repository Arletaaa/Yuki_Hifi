# Arlt HiFi Player Roadmap

## P0: 工程骨架

- 建立 pnpm workspace。
- 建立 Electron + React + Vite 桌面应用骨架。
- 建立 `packages/shared`、`packages/ui`、`packages/agent-harness`。
- 建立产品文档、ADR、提示词、评测计划和 fixtures 占位。

## P1: 桌面应用闭环

- `pnpm dev` 直接启动 Electron 桌面窗口。
- 完善窗口控制、preload API 和主/渲染进程边界。
- 通过 Electron 主进程选择本地音乐文件夹。
- 保持前端调试入口可用。

## P2: 本地音乐库与播放队列

- 递归扫描本地音乐库。
- 展示音乐库列表、空状态、扫描中、扫描失败状态。
- 建立 `library`、`queue`、`currentTrack` 的统一 Zustand 状态。
- 点击曲目载入播放器。
- 后续补充排序、搜索、筛选和队列编辑。

## P3: 真实播放 MVP

- 使用 `HTMLAudioElement` 播放扫描到的本地音频文件。
- 同步播放、暂停、上一首、下一首、进度、时长和播放错误。
- 通过受控媒体协议播放本地音频，避免 renderer 直接访问任意文件路径。
- 处理格式不支持和文件不可读。

## P4: 元数据、封面与 HiFi 信息

- 接入音频元数据解析。
- 提取标题、艺术家、专辑、时长、采样率、位深和封面。
- 区分 mock 信息与真实播放链路信息。
- 设计输出设备、独占模式和 audio-core 的接口边界。

## P5: 音频核心

- 评估并接入 Rust audio-core。
- 建立音频解码、输出设备、采样率、位深和独占模式的接口边界。
- 建立音频链路回归测试。

## P6: 轻量视觉反馈与主题资源

- 定义主题视觉和播放状态反馈资源格式。
- 支持播放栏、封面区域或轻量浮层根据播放状态变化。
- 可选评估桌面伴随模式，但不在主播放器页面保留右侧舞台、角色舞台或动态视觉舞台。
- 后续扩展歌词、主题和专辑视觉联动。

## 当前阶段建议

当前阶段优先完善 P2/P3/P4：音乐库体验、真实播放 MVP、元数据和 HiFi 信息。不要实现 Live2D、视频播放、独立视觉舞台或音频节奏分析，因为这些会干扰本地播放器核心闭环。
