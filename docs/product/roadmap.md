# Arlt HiFi Player Roadmap

> 最后同步：2026-10-30。v1.0 剩余项与建议顺序见 [next-steps](next-steps.md)。

## 已完成

- [x] **S0 基线**：workspace、Electron + React + Vite 骨架、扫描器、媒体协议、播放 MVP、文档体系。
- [x] **S0 修复**：迁移导致的 `node_modules` 失效重建；基线 typecheck/test/build 全绿；git 初始化。
- [x] **S1 需求与 IA**：验收标准表、范围边界（ADR 003/004）。
- [x] **S2 系统层设计系统**：tokens、`packages/ui` 组件、三页骨架、内置夜景壁纸、动效三档、微交互。
  - 说明：视觉方向已被 ADR 005 部分取代——系统层继续沿用，库的主视图改为 3D 场景。
- [x] **S2R-0 场景技术 spike**：three + R3F 接入、单张 CD 可旋转、60/240 张压测、帧率 HUD。
- [x] **S2R-1a 性能与虚拟化**：架子全局实例化 + CD 分段挂载；240/500 张均为 13 draw calls。
- [x] **S3 领域模型 + 收藏**：store 拆 library/queue/playback 切片；`Track` 增加 `coverPath`/`metadataSource`；收藏与队列解耦。
- [x] **S5 扫描 / 元数据 / 封面 / 持久化**：music-metadata + 封面缓存 + `settings.json` + 搜索排序。
- [x] **S2R-1b 画廊可用形态**：封面、点击、hover、搜索飞行、滑动边界与阻尼回弹。
- [x] **S2R-3 转场与播放（方案调整）**：原“悬浮播放台”由“CD 盒详情 + 唱片机”取代；约 1.05s 进入 / 1.0s 返回转场、开盒、取盘、吸附、唱臂落针、播完即停、返回收尾均已实现（`79dd69d`）。
- [x] **CD 唱片机（2026-10-30）**：拆件 GLB、双状态灯、Start/Stop 起停转、唱臂拖拽/自动回架、播放联动、返回合盒、CC-BY 署名。

## 进行中 / 未完成

- [~] **S4 播放链路**：播放/暂停、播完语义、错误映射、音量环已完成；**seek、静音 UI 随旧播放栏删除**，待补。
- [~] **S6 HiFi 信息**：数据层完成（真实格式/采样率/位深，mock 已删除）；**当前 UI 没有展示入口**，待补。
- [~] **S2R-1 长廊与生长**：当前实现是单排货架；Bay 空间模型、24 首一段的生长/消退、跨 Bay 虚拟化未做。
- [~] **S2R-2 长廊交互**：货架拖拽/滚轮/搜索飞行已完成；跨 Bay 两段式移动、双击回当前 Bay 依赖长廊模型，未做；收藏外观未做。
- [~] **S2R-4 降级与可达性**：搜索/设置已有 ARIA；列表视图、无 WebGL 降级、低帧率降级、`motion=off`、完整键盘走查未做。
- [~] **S2R-5 打磨**：接触阴影、三档材质、四档光效、实例化已有；景深/生长时序/纹理 LRU/真机帧率收口未做。
- [~] **S7 生产可用**：esbuild 打包、生产 app 协议、`pnpm start`、用户真机确认已完成；**electron-builder 安装包未实际构建、未装包冒烟**。
- [ ] **S8 收尾**：测试补齐、CI、构建冒烟、验收清单归档。

## 关键待决

1. **画廊形态**：保留单排货架，还是回到“长廊 + Bay 生长”？决定前不投入收藏外观与跨 Bay 移动。
2. **收藏范围**：store 与持久化已有，缺入口与金边外观；是进 v1.0，还是正式移到 v1.1。
3. **v1.0 门禁**：列表降级、键盘全程、seek/静音、HiFi 信息条是否必须补齐；ADR 005 目前把列表视图视为硬要求。

## v1.1（已确认优先级，见 backlog）

- 最近播放 → 静态 LRC 歌词 → 自建播放列表 → 多目录 → 迷你播放器小窗。

## backlog（不在 v1.0）

- Rust audio-core、增量索引、SQLite、主题包、自动更新、崩溃上报、Playwright E2E。
- 场景增强：长廊/Bay（若 v1.0 冻结货架）、CD 物理堆叠与拖拽归位、音频电平驱动灯光、多房间主题、无障碍 overlay 投影网格。

## 约束提醒

- 不做装饰性舞台、角色立绘、Live2D、MV/视频背景。
- 3D 元素必须对应真实收藏或真实播放状态（ADR 005 判定标准）。
- 播放链路在 audio-core 接入前保持 `HTMLAudioElement`，且不得展示无法解释的信号数值。
