# CD 唱片机交互 · 素材可行性 + 需求整理

状态：需求整理（未实现）
日期：2026-10-28
素材：`素材/cd_player.glb`（Sketchfab "CD player"，作者 nguyentrongtam0512，CC-BY-4.0）

## 0. 结论

模型可用，交互可行，但**不能直接拿原 GLB 做交互**（整机是两个合并网格，没有零件层级），
需要一次离线预处理：

1. 把单一网格拆成 `Deck` / `Platter`（转盘+胶垫+主轴）/ `Tonearm`（唱臂）/ `StartStop`（按钮）四个节点；
2. 新增 2 颗状态灯（素材里没有）；
3. 4K 贴图降采样到 1K（29 MB → 6.8 MB）；
4. 重导出 GLB，唱臂/转盘枢轴放在节点原点上，动画全部由 three.js 驱动。

已验证的关键动作：唱臂绕轴承旋转 −52° 可以横扫整个转盘（唱头落在盘心附近），
说明可达性没有问题；实际落针角会校准到 CD 外圈（约 −42°）。
转盘/胶垫/主轴可以整体绕盘心旋转。两项都在 Blender 里渲染确认过。

### 0.1 已确认（2026-10-28）

1. **尺寸**：适配画面，允许微调 CD 尺寸；左 CD 盒、右唱片机，两者比例协调即可。
   → 唱片机宽 2.5–2.6，CD 保持原尺寸（约占转盘 2/3），必要时再调。
2. **倾斜**：32° 后仰确认。
3. **状态灯**：不做新增圆灯。用 Start/Stop 方形按钮右侧的两个内嵌长方形窗口，
   内层矩形发光；左窗口 = 电机状态，右窗口 = 播放状态。
4. **唱臂**：允许停在静止的 CD 上，转盘起转后自动开始播放。
5. **播完即停**：只让转盘减速停止，**不回架唱臂**（机头留在盘上；再点 Start 恢复播放）。
6. **取盘**：转盘旋转中、或唱臂在盘上时，都禁止取 CD。
7. **双击播放**：移除，播放只由唱臂触发。
8. **盘面**：CD 顶面贴专辑封面（外圈、四周留边），与陈列区/交互区使用同一封面。

### 1.1 拆件验证

- **唱臂**：按「x>0.10、z>0.10、min z>0.098」筛连通块，得到 181 块，正好覆盖唱臂管、
  唱头、配重、轴承座；绕 (0.1582, 0.1118) 的 Z 轴旋转 −52° 后，唱头落在
  (-0.048, -0.016)，已经越过盘心，证明整条 CD 都在唱臂行程内。
  按几何估算，唱针落在外圈（距盘心约 5 cm）时约 −42° ~ −45°，扫到盘心约 −50°；
  具体角度要以唱针尖顶点校准。交互上建议松手后吸附到「落针角」而不是跟手停住。
  误选：防滑旋钮和升降杆会跟着转，导出前需要按包围盒剔除（视觉上影响很小）。
- **转盘**：以盘心为圆心、半径 <0.16、z∈(0.075, 0.115) 筛连通块，得到 83 块，
  正好是转盘 + 胶垫 + 中轴，可整体绕盘心旋转。
- **Start/Stop 按钮**：素材里是独立连通块组，位于
  x ∈ [-0.2138, -0.1725]、y ∈ [-0.1651, -0.1294]、z ∈ [0.0806, 0.0833]，
  约 4.1 × 3.6 cm 的浅方形按键，可以单独拆出并做下压动画（下压 ≈1 mm）。
  旁边还有两颗 33/45 小按键（同样独立），本期不接交互。
- **状态灯**：素材里**不存在**，需要新增两颗小圆形 LED。
  建议位置（顶面 z≈0.082，直径 9 mm）：
  - 左灯 (-0.205, -0.100)：Start/Stop 按键后方、左侧边缘；
  - 右灯 (+0.205, -0.100)：右前角、唱臂前方。
  已用 mock 渲染确认可见性（见 `.verify/blender/player-lamp-mock.png`）。
- **CD**：唱片机没有唱片，转盘上只有胶垫；使用现有 `cd-case.glb` 里的 `CD_1`。

### 1.2 性能

- 原始：142,722 tri + 3 张 4096² 贴图 ≈ 200 MB 显存（含 mipmap 约 268 MB）。
- 贴图降到 1024² 后导出 GLB 为 **6.77 MB**，几何不变；屏幕上唱片机约占 500–700 px，
  1K 足够，标签文字仍可读。
- 场景已有 `RoomEnvironment` PMREM 环境光，唱臂/转盘的金属件不会发黑。
- 建议：保留 142k 三角面（可接受）；如要再省，可在 Blender 里对静态 Deck 做 0.5 减面，
  唱臂和转盘不要减。

### 1.3 风险

- 唱臂拆分依赖坐标阈值；模型换版本会失效（当前素材固定，可接受）。
- 素材是白色塑料 + 深灰底座，场景是暖光，需要确认对比度（Blender 渲染偏亮，three.js 里要实看）。
- 素材文字贴图在 UV 里是镜像的，但渲染出来正读（"STOP"/"33"/"45" 正常），不影响。
- CC-BY 需要 App 内署名入口（设置页「关于/致谢」或场景角落）。

## 2. 场景与摆放

### 2.1 现状

- 交互区（detail）是「墙面陈列」构图：相机 (0, 1.78, 6.2) 注视 (0.15, 3.2, 0.1)，
  视线几乎水平、略微仰视；CD 盒竖放在 x=-0.4, y=3.2。
- 右侧本来就是预留给 CD 机的（`INTERACTION_CASE_POSITION` 注释），可用宽度约 3 个场景单位。

### 2.2 倾斜角

因为相机在唱片机下方，"真正平放"的转盘只能看到侧面/底面。要读出「俯视」，
唱片机必须相对墙面后仰 30°–35°（绕 X 轴），此时转盘在画面里是压扁约 0.66–0.69 的椭圆，
接近产品图的 3/4 视角。**不建议超过 40°**：再大反而更看不到盘面。

- 建议：相对墙面后仰 **32°**；模型在 three.js 里是 Y-up，盘面法线 +Y，
  所以实际姿态是 `rotation.x ≈ 58°`（先转 90° 让盘面朝镜头，再后仰 32°），
  可再绕 Y 轴 5°–8° 让唱臂一侧略靠后，增加立体感。
- CD 吸附后与转盘同平面，即同样后仰 32°，符合"CD 倾斜到唱片机的角度"。

### 2.3 尺寸

- CD 直径 ≈ 1.076 场景单位（半径 0.538）。
- 真实比例：唱片机宽 0.4529 m ÷ CD 直径 0.12 m × 1.076 = **4.06 单位**，转盘直径 2.60，
  CD 只占转盘直径 41%。当前 detail 画幅宽约 5.9 单位，4.06 宽会占掉 2/3 画面，
  和左边的 CD 盒比例失衡。
- 建议：唱片机宽 **2.5–2.7 单位**（缩放 ≈5.6），转盘直径 ≈1.6–1.7，
  CD 占转盘直径 ≈0.63–0.67 —— 视觉上像一张 10 吋唱片放在 12 吋转盘上，能接受。
- 占地：宽 2.6、深 2.0、厚 0.80；放在 x≈1.45、y≈3.15、z≈0.15，
  左缘离 CD 盒右缘约 0.2，右缘不出画。

> 尺寸和位置需要浏览器里实看微调，上面的数字是起点。

## 3. 状态定义

| 状态 | 左灯 | 右灯 | 转盘 | 唱臂 | 音频 |
| --- | --- | --- | --- | --- | --- |
| Empty 无盘 | 黑 | 黑 | 停 | 架上 | 停 |
| Ready 盘已就位 | 红 | 黑 | 停 | 架上 | 停 |
| Spinning 转盘转、臂在架上 | 绿 | 黑 | 转 | 架上 | 停 |
| Playing 播放 | 绿 | 绿 | 转 | 在盘上 | 播放 |
| Paused 臂移开 | 绿 | 黑 | 转 | 架上/移动中 | 暂停 |
| Empty（取盘后） | 黑 | 黑 | 停 | 架上 | 停 |

- 左灯语义 = 转盘电机状态（红=待机/有盘，绿=转）。
- 右灯语义 = 播放状态（绿=唱针在盘上且出声）。

## 4. 交互规则

### 4.1 放 CD

- CD 从盒内拖出后，在屏幕空间里移动（保持现有手感）；当 CD 中心进入转盘中心的
  吸附半径（建议 0.35 × CD 半径，按投影后的屏幕距离判定）时高亮/吸附。
- 吸附动画 0.35–0.45 s：位置移到盘心上方，四元数从"竖立"转到"唱片机平面"，
  同时 L 灯黑→红（0.2 s 淡入）。
- 落盘后 CD 可以继续被拖走（只要唱臂不在盘上）；拖走时 L 灯红→黑，
  若转盘在转则先减速停下。
- 松手位置既不靠转盘也不靠盒心时：回到最近的家（建议）。

### 4.2 Start / Stop 按钮

- 点击命中区：Start/Stop 按键的局部包围盒（见 1.1），带 1 mm 下压动画 + 回弹。
- 只在「有盘 + 唱臂不在盘上」时响应；否则忽略（或轻微抖动提示）。
- 起转：0 → 33⅓ rpm，加速 1.2 s（ease-in），L 红→绿。
- 停转：33⅓ rpm → 0，减速 1.6 s（ease-out），L 绿→红。
- 转盘转时再点：只减速，不影响音频；如果唱臂在盘上，是否同时暂停见 §7。
- 转盘（胶垫、频闪点）与 CD 一起转，转速相同；转盘可反向对齐。

### 4.3 唱臂

- 命中区：唱臂整组（唱头/臂管/配重）。按下后进入拖拽，光标 grabbing。
- 拖拽映射：指针水平位移 → 绕轴承旋转（建议 0.35°/px），限制在
  [静止位, 过盘心 8°] 之间；可加少量垂直位移映射到抬臂高度。
- 拖拽中唱臂抬起 ≈8 mm（避免蹭盘）；松手时：
  - 落在正在旋转的 CD 上 → 降臂到盘面，开始播放，R 黑→绿；
  - 落在 CD 上但转盘没转 → 不播放（见 §7-4）；
  - 没落在 CD 上 → 0.3 s 缓动回架上；
  - 没有 CD → 直接回架上，不响应"放上"。
- 播放中把唱臂拖走 → 立即暂停，R 绿→黑；唱臂回架上。
- 播放中唱臂再拖回盘上 → 继续播放（同一首）。
- 播放时 CD 不可拖动：命中 CD 时给拒绝反馈（轻微回弹/光标 not-allowed），不进入拖拽。

### 4.4 播完即停（`playbackMode === "stop"`）

- 当前曲目 ended → 自动：抬臂 → 回架 → R 绿→黑 → 转盘减速停止 → L 绿→红。
- CD 留在转盘上，状态回到 Ready。
- 循环播放模式（`repeat-one`）不触发，唱臂保持在盘上。

### 4.5 返回（任何时候）

点击返回后，无论当前处于拖拽、播放、旋转还是吸附中，都按下面顺序收尾：

1. 取消正在进行的拖拽（唱臂/ CD）；
2. 若在播放：暂停音频；
3. 唱臂抬起并回架（0.3 s）；
4. 转盘减速停止，L→黑；
5. CD 从转盘飞回盒内卡口（0.6–0.8 s，含姿态回正）；若 CD 已在盒内则跳过；
6. 盒盖合上（现有 `buildClosePlan` 的关闭逻辑）；
7. 执行现有 returning 转场，唱片机随场景一起淡出/离场。

要求：整个收尾期间禁用手势（返回按钮只触发一次），动画结束才进入 returning。

### 4.6 自动归位（用户明确要求）

- 无 CD 时拖唱臂：松手自动回架。
- 有 CD 但没拖到 CD 上：松手自动回架。
- 返回时：不管唱臂在哪，都回架。

## 5. 动画参数（建议值）

| 项目 | 参数 |
| --- | --- |
| CD 吸附 | 0.4 s，位置 easeOutCubic，姿态 slerp |
| CD 回盒 | 0.7 s，先抬后飞（弧线） |
| 唱臂摆动 | 0.3 s，临界阻尼 |
| 抬臂/落臂 | 0.12 s / 0.18 s |
| 起转/停转 | 1.2 s / 1.6 s（ease-in-out） |
| 转速 | 33⅓ rpm ≈ 200°/s |
| 灯色过渡 | 0.2 s |
| 按钮下压 | 0.08 s 下、0.12 s 回 |

## 8. 验收标准

1. CD 拖到唱片机附近会吸附到盘心，姿态与唱片机平面一致；左灯黑→红。
2. 点 Start/Stop：CD 由缓到快旋转，左灯红→绿；再点：慢慢停，左灯绿→红。
3. 唱臂在架上时可以把 CD 拖走；唱臂在盘上时拖 CD 无效。
4. 唱臂拖到旋转中的 CD 上：开始播放，右灯黑→绿；拖走：暂停，右灯绿→黑。
5. 唱臂没拖到 CD 上/无 CD：松手自动回架。
6. 「播完即停」模式下曲目结束：唱臂自动回架、转盘减速停止、右灯灭、左灯红。
7. 任何状态下点返回：唱臂回架、CD 回盒、盒盖合上，再执行返回转场；过程中不会闪烁/跳变。
8. 控制台无报错；场景帧率不低于现状；首次进入 detail 的加载时间可接受（GLB ≤7 MB）。
