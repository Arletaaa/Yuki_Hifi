# 场景展厅规格（Scene Gallery）

> 决策依据：[ADR 005](../decisions/005-scene-gallery.md)。本文档是 S2R 系列阶段的实现与验收依据。

## 1. 概念

一个会随收藏长大的房间。收藏第一首时房间是空的，只有一束射灯和一座空底座；收藏越多，房间从"桌上的木箱"长成"整面墙架"，再长成"档案馆"。每一张 CD 都对应一首真实收藏的曲目，盘面印着它的封面。

镜头是这个空间里的"人眼"：可以环视、拉近、停在某一张 CD 前。点击 CD，它从架上被抽出、转向你、然后飞进播放台。

## 2. 分档（装置演进）

阈值由 `getGalleryTier(count)` 计算，纯函数、可单测。

| 档位 | 收藏数 | 储存装置 | 环境变化 | 镜头 |
| --- | --- | --- | --- | --- |
| `empty` | 0 | 空底座 + 一束射灯 | 暗房间、缓慢尘埃 | 缓慢推近底座 |
| `crate` | 1–8 | 桌面木质小箱，CD 靠放 | 一盏台灯暖光 | 桌面高度，可环绕 120° |
| `shelf` | 9–19 | 两层木架，CD 竖排 | 台灯 + 窗外夜色 | 半身高度，可环绕 180° |
| `wall` | 20–49 | 整面墙架（4 层） | 霓虹小招牌、窗、地面反光 | 房间中心，可 360° 环视 |
| `studio` | 50–99 | 双墙架 + 唱机台 + 单人沙发 | 城市夜景、体积光 | 房间中心，可低角度仰视 |
| `archive` | 100+ | 纵深三级档案架（实例化重复） | 雾、缓慢扫过的顶光 | 受限（防迷失），支持搜索飞行 |

**约束**：档位切换只在收藏数量跨越阈值时发生，播放、暂停、切歌不得改变装置；切换有 600ms 的过渡（灯光先变，装置后变）。

## 3. 交互

### 3.1 场景浏览

| 操作 | 行为 |
| --- | --- |
| 拖拽空白处 | 环绕镜头（带阻尼，松手后惯性衰减） |
| 滚轮 | 推拉镜头（限制在档位允许的范围内） |
| 双击空白处 | 镜头复位到该档位默认机位 |
| 悬停 CD | CD 抽出 2mm、正面朝向镜头 8°、浮出标题/艺术家标签 |
| 点击 CD | 进入转场（见 §4） |
| 右键 CD | 轻量菜单：从此曲播放 / 查看详情 / 取消收藏 |
| 悬停空位（未满档） | 显示"还能放 N 张"的微弱提示，不抢注意力 |

### 3.2 键盘与读屏

| 按键 | 行为 |
| --- | --- |
| `Tab` | 进入场景焦点 → 遍历可见 CD（按屏幕投影顺序）→ 离开 |
| `Enter` | 打开当前聚焦的 CD |
| `L` | 切换到列表视图（等价于设置里的"始终使用列表视图"） |
| `Esc` | 退出播放台回到场景 / 关闭菜单 |

- 聚焦的 CD 必须有可见描边（不许只有 3D 高亮）。
- 每次焦点变化通过 `aria-live="polite"` 播报「第 N / 共 M 张：曲名 — 艺术家」。
- 场景 canvas 本身 `aria-hidden="true"`，可访问性由叠加的按钮层承担。

### 3.3 收藏变化

- 新增收藏：新 CD 从上方落入空位（`standard` 档：200ms 淡入 + 落位；`rich` 档：落位回弹 + 一圈尘埃）。
- 取消收藏：CD 轻微上浮后缩小消失（180ms），空位保留到下一次重新排布。
- 跨越阈值：先播灯光过渡，再替换装置（600ms），期间输入被锁定但不卸载控件。

## 4. 转场（场景 → 播放台）

| 帧 | 内容 | 时长 |
| --- | --- | --- |
| 0–180ms | 选中的 CD 从架上抽出，其他 CD 轻微后退并变暗 | 180ms |
| 180–400ms | CD 升起、转向镜头，房间灯光收束成一束聚光 | 220ms |
| 400–750ms | 镜头推近，CD 移至屏幕中央并放大到播放台尺寸，环境虚化 | 350ms |

- 总时长 750ms，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。
- `motion=off` 或 `prefers-reduced-motion` → 直接切换（无位移，仅 120ms 交叉淡入）。
- 返回：CD 旋转缩小、沿原路径回到架上原位（400ms），期间不可再次点击。

## 5. 播放台

- **主体**：一张悬浮的 CD，直径约占视口 38%，默认略低于中心。
- **倾斜**：鼠标在窗口内移动 → CD 围绕 X/Y 轴倾斜 ±12°，带阻尼（插值系数 0.08），鼠标离开窗口回正。
- **转动**：播放时绕自身法线匀速转动，6s/圈（可视舒适度优先于真实 33⅓ rpm）；暂停时缓停并停在当前角度。
- **盘面**：印当前封面；中心孔、边缘彩虹衍射用程序化贴图模拟（不做真实光栅着色）。
- **光影**：单一主光 + 粉色轮廓光；下方接触阴影与柔和倒影。
- **控制层**：复用系统层组件（播放/暂停、上一首/下一首、进度、音量旋钮、模式），悬浮在场景之上，永不遮挡标题与进度。
- **信息层**：曲名、艺术家、专辑、格式/采样率/位深/质量 chip 固定在下方。
- **返回**：左上角「返回展厅」按钮 + `Esc`。

## 6. 材质与光照语言

- 低多边形 + 强轮廓光：几何不追求写实细节，靠边缘光与材质反射建立质感。
- 调色：深靛蓝房间（#0a0d16 系）+ 樱花粉轮廓光（#ff7aa8）+ 青色冷光补光（#78d8ff）。
- 禁止写实贴图与 HDRI 素材（体积大且版权风险）：环境用程序化渐变 + 少量点光。
- CD 盘面：金属度 0.9 / 粗糙度 0.15；外壳（jewel case）：半透明 + 菲涅尔边缘。
- 尘埃：仅 `rich` 档，屏幕占比 < 3%，不做满屏飘雪。

## 7. 性能预算

| 指标 | 预算 |
| --- | --- |
| 帧率 | 1280×820 窗口 ≥ 50fps（Intel 核显），≥ 60fps（独显） |
| 像素比 | `dpr` 上限 1.5，低帧率时降到 1.0 |
| 首帧 | 场景 JS 懒加载，系统层首帧 ≤ 300ms 不受影响 |
| 静止 | 最后一次交互 800ms 后停止渲染（`frameloop="demand"`） |
| 纹理 | 封面 512²、LRU 常驻 ≤ 48 张、总显存 ≤ 128MB |
| 几何 | CD 复用同一几何；> 24 张启用 `InstancedMesh` |
| 阴影 | 单方向光，shadow map 1024；不做实时级联阴影 |
| 窗口隐藏/失焦 | 立即停止渲染 |

## 8. 降级策略

| 触发条件 | 降级行为 |
| --- | --- |
| WebGL2 不可用 / 上下文创建失败 | 直接进列表视图，设置页显示原因 |
| `motion=off` 或系统减少动效 | 静态场景（渲染一帧后冻结）+ 列表视图可切 |
| 连续 3 秒 < 30fps | 自动降为静态场景 + 提示"已为流畅度降级"，可手动恢复 |
| 收藏 > 300 | 默认列表视图；场景只陈列最近 60 张 + 搜索入口 |
| 收藏 = 0 | 场景即引导页：空底座 + 「收藏第一首」入口 |

## 9. 验收标准（S2R 门禁）

| # | 验收项 | 判定 |
| --- | --- | --- |
| G1 | 六档装置随收藏数正确切换 | 单测 `getGalleryTier` + 六张截图 |
| G2 | 悬停/点击/键盘三种命中路径都可用 | 手测 |
| G3 | 转场 750ms 内完成且不丢帧 | 录屏/帧率采样 |
| G4 | 播放台 CD 随鼠标倾斜、播放时转动、暂停缓停 | 手测 |
| G5 | 1280×820 下 ≥ 50fps | 内置帧率 HUD（开发模式）读数 |
| G6 | 静止 800ms 后渲染计数为 0 | 帧率 HUD 显示 |
| G7 | WebGL 关闭时自动进入列表视图且功能完整 | 手测（禁用 WebGL 启动） |
| G8 | `motion=off` 无位移动画 | 手测 |
| G9 | 键盘可完成浏览→打开→播放→返回 | 手测（不碰鼠标） |
| G10 | 读屏能播报当前聚焦曲目 | 手测 + DOM 检查 |
| G11 | 场景不可遮挡播放控制与错误提示 | 截图核对 |
