# 场景展厅规格（Scene Gallery）— CD 长廊

> 决策依据：[ADR 005](../decisions/005-scene-gallery.md)。本文档是 S2R 系列阶段的实现与验收依据。
> 第二轮修订（2026-10-24）：曲库**全部**入场、收藏只改变外观、成长表现为长廊向外延伸、镜头沿走廊移动。原"六档房间替换"模型作废。

## 1. 概念

一条沿纵深延伸的 CD 长廊。曲库里的每一首都在场，按顺序陈列在架位上；收藏的 CD 有独特外观（金边 + 边缘微光），在长廊尽头也能一眼认出。

曲库越长，长廊越长——超出现有房间的部分会"生长"到场景之外。镜头沿着走廊移动：你不用环视整个曲库，你只需要走到想看的那一段。

## 2. 空间模型（可测的纯函数）

```
index（曲库顺序）
  → anchor = { bay, slot, side }
  → world  = { x, y, z }
```

| 概念 | 定义 |
| --- | --- |
| Bay（展示段） | 长廊的一个单元，含 24 个 Slot（4 层 × 6 位），左右交替布位 |
| Slot | 单个 CD 位，间距固定，空位保留 |
| Bay 深度 | 1.8 世界单位；Bay 宽度 3.6 |
| 眼高 | 1.6 单位 |
| 初始房间 | Bay 0：带家具、窗、顶灯（唯一"房间"形态） |
| 长廊 | Bay 1+：更简洁的金属档案架，远处接雾 |

纯函数（必须单测，边界 0/1/23/24/25/47/48）：

```ts
getGalleryAnchor(index: number): { bay: number; slot: number; side: "left" | "right" }
getBayCount(trackCount: number): number   // ceil(trackCount / 24)
```

## 3. 生长规则

- 成长由**曲库数量**驱动，不由收藏数量驱动（收藏只决定外观）。
- 每满 24 首，向长廊末端增加一个 Bay。
- 新增 Bay 有 600ms 生长动画：架子从地面升起 → 顶灯依次点亮 → 这一段的雾推远一点。
- 曲库缩减（换目录/刷新）导致 Bay 消失时：CD 淡出 → 架子下降 → 雾回推，不保留空 Bay。
- 空曲库：Bay 0 保留为引导位（空底座 + 「导入曲库」入口）。

## 4. 镜头与移动

镜头始终在走廊中轴附近、面向纵深，**不做自由飞行**（限制 pitch ±18°，避免晕眩与穿模）。

| 操作 | 行为 |
| --- | --- |
| 拖拽（横向） | 沿走廊平移；松手后惯性衰减 |
| 滚轮 | 沿 Z 轴前后推进（不是缩放） |
| 上下拖拽（限制内） | 轻微俯仰，用于看上层/下层 |
| 双击空白 | 回到当前播放曲目所在 Bay 的标准机位 |
| 点击远处 CD | 相机沿走廊滑行到该 Bay（见 §7） |
| 自动漂移 | 默认关闭；「丰富」动效档可开启极慢前行，任何输入立即打断 |

## 5. 流式加载与虚拟化

长廊必须按相机位置虚拟化，否则 500 首会直接爆显存。

- 常驻范围：相机所在 Bay ±2；其余 Bay 卸载几何与材质实例。
- 封面纹理池：512²，LRU 常驻 ≤ 48 张，超出后释放。
- Bay 的 CD 使用 `InstancedMesh`（同一几何、材质变体 2 种：普通 / 收藏）。
- 预取：相机移动方向上的下一个 Bay 提前 400ms 开始加载纹理。

## 6. 收藏的特殊外观

要求"一眼认出"但不是"游戏道具发光"：

| 特征 | 实现 |
| --- | --- |
| 金边 | 盘缘金属环（金属度 1、粗糙度 0.15、暖金色） |
| 边缘微光 | 极窄的 emissive 描边，强度低（不泛光到整张 CD） |
| 架位标记 | 该 Slot 上方一枚小金色三角，从远处可辨 |
| 非颜色冗余 | 列表视图里收藏项额外显示 ★ 与「收藏」文本，不只靠颜色区分（色盲友好） |

设置项：`场景高亮收藏`（默认开）。关闭后收藏 CD 与普通 CD 外观一致，但仍可从列表与播放台看到收藏状态。

## 7. 移动与搜索飞行

- **相邻 Bay（≤ 2）**：直接滑行，400ms。
- **远处 Bay（> 2）**：两段式——先淡出到目标前 2 Bay（180ms），再滑行入场（320ms），避免长距离掠过造成眩晕与卡顿。
- **搜索**：输入即时过滤（非匹配 CD 降亮度 40%），`Enter` 飞到第一个匹配；连续 `Enter` 在匹配间跳转。
- 飞行期间禁止再次触发飞行（排队或忽略），避免镜头抖动。

## 8. 写实风格与性能

用户要求"偏写实"。这里的写实指**光照与材质可信**，不是照片级：

- PBR 材质（金属度/粗糙度/清漆层），CD 盘面用 iridescence 近似衍射。
- 环境光：程序化 PMREM（软箱 + 渐变天空），**不使用下载的 HDRI 或贴图素材**（体积与版权风险）。
- 单方向主光 + 粉色轮廓补光 + 接触阴影（1024）。
- 轻微景深（可选，低帧率时第一个被关掉）。

| 指标 | 预算 |
| --- | --- |
| 帧率 | 1280×820 ≥ 45–50fps（Intel 核显），独显 ≥ 60fps |
| 像素比 | 上限 1.25，低帧率降到 1.0 |
| Draw call | ≤ 120/帧（每个 Bay 的架子合并为单几何） |
| 纹理 | 封面 512²、LRU ≤ 48、总显存 ≤ 128MB |
| 静止 | 800ms 无交互后停止渲染 |
| 首帧 | 场景 JS 懒加载，系统层首帧不受影响 |

降级顺序（保长廊、砍效果）：景深 → 接触阴影 → 环境反射 → 静态场景 + 列表视图。

## 9. 交互与可达性

| 操作 | 行为 |
| --- | --- |
| 悬停 CD | 抽出 2mm、朝向镜头 8°、浮出曲名/艺术家 |
| 点击 CD | 转场进入播放台 |
| `Tab` | 进入场景焦点 → 沿当前 Bay 内的 Slot 顺序遍历 → 离开 |
| 方向键 | 左右换位、上下换层；跨 Bay 自动滑行 |
| `Enter` | 打开当前聚焦 CD |
| `Esc` | 播放台返回场景 / 关闭菜单 |
| `L` | 切换列表视图 |

- 场景 canvas `aria-hidden`，可访问性由叠加的 DOM 按钮层承担（按投影位置排布，仅覆盖可见 Bay）。
- 焦点变化通过 `aria-live="polite"` 播报「第 N / 共 M 首：曲名 — 艺术家」。
- 所有交互都必须有键盘等价路径。

## 10. 播放台

- 悬浮 CD，直径约占视口 38%，随鼠标倾斜 ±12°（阻尼 0.08），播放时转动 6s/圈，暂停缓停。
- 盘面印封面；盘心孔、边缘衍射为程序化效果；下方接触阴影与柔和倒影。
- 控制层与信号信息悬浮在场景之上，永不遮挡。
- 返回：CD 旋转缩小，沿原路径回到架上原位（400ms）。
