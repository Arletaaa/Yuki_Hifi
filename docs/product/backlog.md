# Backlog（超出当阶段范围的想法）

这里只记录不在当前工作流范围、但值得未来评估的事项。**记录不等于承诺**，任何一项要实施都需要新的 ADR 与验收标准。

## 音频与 HiFi 链路

- Rust audio-core：解码、位深转换、输出设备枚举、独占模式（WASAPI/ASIO）。
- 真实标签解析（ID3 / Vorbis / FLAC metadata）与专辑封面提取、封面缓存。
- 无缝播放（gapless）、交叉淡入淡出、重采样策略可选。

## 音乐库

- 多目录 / 监听文件夹变更。
- 播放列表（用户自建）、收藏、最近播放。
- 增量索引与持久化数据库（SQLite）。

## 界面

- 浅色/深色主题跟随系统、主题包。
- 歌词展示（静态 LRC，不含滚动特效）。
- 桌面伴随模式（可关闭的独立小窗）。

## 工程

- Playwright / agent-browser 端到端回归与截图基线。
- 自动更新、崩溃上报、性能埋点。

## 明确不做

- 右侧舞台、角色舞台、Live2D、看板娘、MV 播放、动态视觉舞台。
- 在线流媒体、云同步、账号体系、社交功能。
