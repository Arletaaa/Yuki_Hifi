# Backlog（超出 v1.0 范围的想法）

这里只记录不在当前工作流范围、但值得未来评估的事项。**记录不等于承诺**，任何一项要实施都需要新的 ADR 与验收标准。

> 已定入 v1.0 的项：
> - 元数据解析与封面提取（[ADR 003 §5](../decisions/003-v1-scope.md)）
> - 单排 3D 货架 + CD 盒 + 唱片机（[ADR 007](../decisions/007-v1-scope-convergence.md)）

## v1.1 优先级（按实施顺序）

| 顺序 | 项目 | 说明 | 成本 |
| --- | --- | --- | --- |
| 1 | 最近播放 | 纯状态与持久化 | 小 |
| 2 | 静态 LRC 歌词 | 同名 `.lrc` 自动匹配，当前行高亮，不做滚动特效与联网歌词 | 中 |
| 3 | 自建播放列表 | 本地歌单的增删改与排序 | 中 |
| 4 | 多目录 | 目录数组、合并去重、设置页管理 | 中 |
| 5 | 迷你播放器小窗 | 无边框独立窗口，封面 + 基础控制；不做角色 | 中高 |

## 场景展厅增强（v1.0 之后）

- 长廊 / Bay 生长 / 跨 Bay 移动：v1.1+ 可选方向，需另开 ADR 重新定义空间模型与验收。
- CD 的物理堆叠与拖拽归位（引入轻量刚体或手写弹簧；v1.0 用插值动画）。
- 音频电平驱动的灯光与盘面反射（不做满屏粒子）。
- 多房间主题（不同房间风格 = 场景皮肤包），与主题包格式一起设计。
- 无障碍投影网格：把每张 CD 投影成可聚焦 DOM 按钮，替代“列表视图”这一整体降级。

## 音频与 HiFi 链路

- Rust audio-core：解码、位深转换、输出设备枚举、独占模式（WASAPI/ASIO）。
- 无缝播放（gapless）、交叉淡入淡出——受限于 `HTMLAudioElement`，应等 audio-core 一起做。
- 重采样策略可选。

## 音乐库

- 监听文件夹变更、自动增量扫描。
- 增量索引与持久化数据库（SQLite）——只在曲库达到数千级后再评估。
- 标签写回、封面编辑、联网抓取封面。

## 界面

- 列表视图 / 无 WebGL 降级：不阻塞 v1.0，若后续有低成本方案再评估。
- 内置展示字体（拉丁 + 日文假名子集），当前使用系统字体栈。
- 主题包格式与加载器、第三方主题分发。
- 从封面取色驱动界面强调色（需先做取色算法与对比度兜底）。

## 工程

- 构建产物冒烟测试（headless 加载 `dist` 断言根节点有内容）——已计划放入 S8。
- Playwright / agent-browser 端到端回归与截图基线（含场景帧率基线）。
- 自动更新、崩溃上报、性能埋点。

## 明确不做

- 装饰性右侧舞台、角色立绘、Live2D、看板娘、MV 播放、与内容无关的动态视觉装饰。
- 在线流媒体、云同步、账号体系、社交功能。
- 写实级 3D（PBR 素材、HDRI、角色模型）。
