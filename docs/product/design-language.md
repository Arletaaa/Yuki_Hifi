# Arlt HiFi Player Design Language

> 方向：「夜空唱片室」。见 [ADR 004](decisions/004-visual-direction.md)。
> 本文档是 S2 设计系统与后续所有界面改动的验收依据；实现落地到什么程度，以本文档的"验收检查项"为准。

## 1. 一句话气质

深夜独自听歌的桌面工具：安静的深色底、一层磨砂面板、樱花粉只在"正在播放"的地方亮一下。

## 2. 分层

| 层 | 内容 | 规则 |
| --- | --- | --- |
| 背景层 | 用户壁纸 / 内置渐变 / 暗化模糊 / 颗粒 | 永远在最底层，不可点击，不承载信息 |
| 系统 UI 层 | rail、列表、播放栏、按钮、菜单、设置 | 对比度与可读性优先，壁纸不得干扰 |
| 内容层 | 曲目信息、信号信息、队列 | 数据可信、状态明确 |
| 反馈层 | 播放态高亮、hover、加载、错误 | 轻、短、可关闭 |

## 3. 色彩

深色为默认主题，浅色为可选主题（同一套 token 两套值）。

| Token | 深色值 | 用途 |
| --- | --- | --- |
| `--bg-base` | `#0a0d16` | 窗口底色 |
| `--surface` | `rgba(20, 24, 38, 0.72)` | 面板 |
| `--surface-strong` | `rgba(28, 33, 50, 0.92)` | 弹层、播放栏 |
| `--line` | `rgba(255, 255, 255, 0.08)` | 1px 描边 |
| `--text` | `#eef1f8` | 主文字 |
| `--text-dim` | `#98a2ba` | 次级文字 |
| `--accent` | `#ff7aa8` | 樱花粉：正在播放、选中、主操作 |
| `--signal` | `#78d8ff` | 青色：格式/采样率/链路信息 |
| `--ok` / `--warn` / `--danger` | `#7be0b6` / `#ffc46b` / `#ff6b8a` | 状态 |

规则：`--accent` 面积不超过一屏 10%；`--signal` 只用于信号类文本，不做按钮底色；禁止紫色到蓝色的通栏渐变。

## 4. 字体

| 用途 | 字体 |
| --- | --- |
| 中文 UI | `"Microsoft YaHei UI", "PingFang SC", "Hiragino Sans GB", sans-serif` |
| 展示（页面标题、曲名） | 打包一个拉丁可变展示字体（S2 定稿，SIL OFL），失败时回退到中文栈 |
| 数字/时长/采样率 | `ui-monospace, "Cascadia Mono", Consolas, monospace` + `font-variant-numeric: tabular-nums` |
| 装饰小标签 | 全大写拉丁 + 0.12em 字距 + 11px，或日文假名小字 |

禁止：默认系统字体直接当标题、字号跳跃无层级、数字不等宽导致进度跳动。

## 5. 布局

```
┌──────┬────────────────────────────────────────┐
│ rail │  content panel                          │
│ 88px │  （页面标题 + 操作区 + 列表/内容）        │
├──────┴────────────────────────────────────────┤
│ player bar 108px                               │
└────────────────────────────────────────────────┘
```

- rail：品牌 + 三个导航（音乐库 / 播放队列 / 设置），竖排中文标签 + 图标，底部版本号。
- 内容面板：单张面板，内边距 24px，不浮动、不叠层。
- 播放栏：左「正在播放（封面 + 标题/艺术家）」，中「传输控制 + 进度」，右「信号 chip + 音量 + 模式」。
- 信号 chip 点击展开 popover（临时浮层，可 Esc/点外部关闭），**不设常驻右栏或舞台**。
- 最小窗口 1024×680；宽度 ≤ 1200 时 rail 收窄为 64px 仅图标。

## 6. 组件规则

- 圆角：小控件 6px、面板 14px、胶囊按钮 999px。
- 描边：一律 1px `--line`，不叠加装饰边框。
- 按钮高度：40px（默认）/ 32px（紧凑）/ 48px（主操作）。
- 焦点：`outline: 2px solid var(--accent)` + `outline-offset: 2px`，任何交互元素都必须键盘可达。
- 状态：空、加载中、失败、禁用必须有独立视觉；失败必须给出可执行动作。
- 列表行：高度稳定，hover 只改变背景与描边，不位移、不改变行高。

## 7. 动效与拟物交互

趣味来源是「拟物控件 + 编排感」，不是装饰动画铺屏。

| 档位 | 内容 |
| --- | --- |
| 关闭 | 全部瞬时完成，仅供无障碍与低性能环境 |
| 标准（默认） | 状态过渡 160–220ms、切页与列表编排、按钮 hover 反馈、唱片静止 |
| 丰富 | 标准 + 唱片转动（24s/圈）+ 唱针动画 + 指针视差（±6px）+ 封面光晕 |

- 缓动：`cubic-bezier(0.22, 1, 0.36, 1)`；编排 stagger 40–60ms，单次总时长 ≤ 400ms。
- 拟物控件：黑胶 + 唱臂（播放栏）、音量旋钮（拖拽/滚轮/键盘均可操作，带数值读数）。
- `prefers-reduced-motion: reduce` 强制等于「关闭」，设置项不得覆盖系统偏好。
- 禁止：常驻满屏粒子/落樱/雨雪、视频或动态壁纸、按时序循环的舞台动画、抢注意力的无限循环、导致布局跳动的动效。

## 8. 背景层规则

- 默认使用内置原创 SVG 夜景（夜空/月/夜桜/灯带），随主题换色调。
- 支持静态图片壁纸：用户选择、可暗化（0–60%）、可模糊（0–12px）、可一键换回默认。
- 壁纸层叠一层 `--bg-base` 的 62% 蒙版 + 细颗粒噪点，保证正文可达 4.5:1 对比度。
- 壁纸不参与布局、不可点击；允许指针视差（±6px，仅在「丰富」档启用）。
- 不允许：角色立绘舞台、Live2D、看板娘、MV、视频壁纸、按时序变化的动态舞台。

## 9. 禁止项

- 高饱和霓虹、游戏 HUD、发光按钮、多层装饰边框。
- 通栏彩色渐变、糖果色渐变按钮。
- 浮动面板遮挡列表、菜单或播放控制。
- 主题或壁纸改变基础交互规则。
- 主播放器页面出现右侧舞台、角色舞台或动态视觉舞台。

## 10. 验收检查项（S2 门禁）

- [ ] 1440×900 与 1024×680 两档截图：无遮挡、无横向滚动、长标题不溢出。
- [ ] 深色/浅色两套主题均通过对比度检查（正文 ≥ 4.5:1）。
- [ ] 壁纸开启（亮色图）时正文仍可读，蒙版生效。
- [ ] 所有按钮有 hover / focus-visible / disabled 三态。
- [ ] Tab 可以走完 rail → 内容 → 播放栏，焦点环可见。
- [ ] 动效三档（关闭/标准/丰富）可切换，且 `prefers-reduced-motion` 生效。
- [ ] 音量旋钮可用鼠标拖拽、滚轮与方向键操作，读数同步。
- [ ] 拟物唱片在「丰富」档转动、「标准」档静止，切换无布局跳动。
- [ ] 默认 SVG 夜景与自定义壁纸都能正常渲染，切换不闪白。
