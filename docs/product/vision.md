# Arlt HiFi Player Vision

Arlt HiFi Player 面向关注本地 HiFi 音乐播放体验的用户。产品希望把可靠的本地音乐管理、真实播放控制、清晰的音频链路信息和安静精致的桌面体验结合起来。

## 产品定位

Arlt HiFi Player 是一个本地 HiFi 桌面播放器。它的核心不是“把网页播放器搬到桌面”，而是围绕本地音乐库、播放体验、音频链路可信度和可长期扩展的桌面能力建立应用。

## 产品原则

- 本地优先：用户的音乐库、播放状态和偏好应优先服务本地文件体验。
- 播放可信：播放、暂停、切歌、进度和错误状态应反映真实音频状态。
- HiFi 可见：采样率、位深、输出设备、独占模式等信息应清晰呈现；尚未真实接入时必须明确边界。
- 安全边界清晰：React 不直接访问 Node/Electron；文件系统能力由主进程和 preload API 控制。
- UI 克制：核心界面是 3D CD 货架、CD 详情 / 唱片机、设置与音量环，不保留装饰性右侧舞台、角色舞台或与内容无关的动态装饰。
- 空间化曲库：曲库不是一张表格，而是可横向滑动的单排 CD 货架——每张专辑都在场，点击后进入 CD 盒与唱片机。场景即内容、即导航，不是背景装饰（[ADR 005](../decisions/005-scene-gallery.md)、[ADR 007](../decisions/007-v1-scope-convergence.md)）。
- 可选视觉反馈：播放状态、场景材质和光效可以增强体验，但只能作为轻量、可关闭、不会遮挡核心操作的增强层。
- 二次元审美，工具内核：用深夜夜色、樱花粉信号色、有性格的排版传达二次元气质，但交互模型必须是桌面音乐工具，不是游戏界面或角色看板。

## 长期方向

- 完善本地音乐库索引、搜索、排序和标签管理。
- 接入音频元数据解析、专辑封面和缓存。
- 先打磨单排 CD 货架的容量、分组与浏览效率；长廊 / Bay 作为 v1.1+ 的可选方向，不承诺。
- 评估 Rust audio-core，用于解码、输出设备、采样率、位深和独占模式控制。
- 建立播放质量评测和回归测试（含场景帧率基线）。
- 可选评估桌面伴随模式或轻量浮层，但不得成为主播放器页面骨架要求。
- 可插拔主题包、专辑视觉和播放状态反馈资源。
- AI-assisted feature、bugfix、review 工作流。
