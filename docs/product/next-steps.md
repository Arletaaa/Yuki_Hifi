- 2026-10-29 23:55 有 `dist` / `dist-electron` 构建产物，晚于最后一次源码改动。
- **未验证**：最新提交后的 `pnpm test` / `pnpm build` 未在受限会话复跑；Windows 安装包从未实际构建。

## 2. 结论

v1.0 缺的不是“能演示的功能”，而是三件事：

1. **可交付闭环**：测试/构建/安装包/装包冒烟。
2. **产品口径统一**：当前实现与原 MVP 在画廊形态、收藏、播放控制上有冲突。
3. **日常可用性**：列表降级、键盘、seek/静音、HiFi 信息条。

建议在 P0 完成前不再新增场景功能。

## 4. P1：v1.0 产品缺口与待决

### 4.1 画廊形态：单排货架 vs 长廊/Bay（需决策）

- **现状**：`gallery-stage.tsx` 是单排货架（同时可见 7 张），没有 Bay、生长、跨 Bay 移动。
- **原承诺**：MVP / ADR 005 / `scene-gallery.md` 描述“每 24 首一个 Bay 的 CD 长廊”。
- **选项**：
  - A. v1.0 冻结货架，修订 ADR/MVP，把长廊/Bay 移到 v1.1+；
  - B. 恢复长廊/Bay，补 `getBayCount` / `getGalleryAnchor`、生长动画、跨 Bay 虚拟化。
- **建议**：A。当前货架已可用且性能可控；长廊是独立的大阶段，不应阻塞 v1.0 交付。
- **验收（若 A）**：ADR 005 / MVP / README / scene-gallery 明确写“v1.0 为货架，长廊列入 v1.1+”。

### 4.2 收藏（需决策）

- **现状**：store、`settings.json` 持久化、单测都有；没有收藏按钮、金边/微光外观、列表 ★。
- **原承诺**：A25 / A33，ADR 005 的核心外观语义。
- **选项**：v1.0 做最小闭环（详情页 ★ + CD 金边）；或正式移出 v1.0。
- **建议**：若只做“详情页切换 + 金边”，成本小，建议进 v1.0；否则移出并同步删除验收项，避免“有数据没入口”。

### 4.3 降级与可达性

- [ ] **列表视图**：WebGL 不可用 / 低帧率时降级（ADR 005 明确要求保留，当前已删除）。
- [ ] **键盘全程**：浏览 → 打开 CD → 播放/暂停 → 返回（A16 / A32）。
- [ ] **动效与主题入口**：`AppSettings` 仍有 `theme` / `motionTier`，但设置浮层没有入口；补 `motion=off` 并跟随系统偏好（A19）。
- [ ] **低帧率降级**：连续 < 30fps 3 秒降到静态场景 + 列表。
- 验收：禁用 WebGL 仍可完成播放；Tab/Enter/Space 可走完全流程；动效关闭后无残余旋转/生长动画。
- 建议：进 v1.0，属于 ADR 门禁而不是“后续优化”。

### 4.4 播放控制与 HiFi 信息

- **现状**：播放栏删除后，UI 没有 seek、静音、进度、格式/采样率/位深展示；store 与标签解析仍在。
- **原承诺**：A9 / A13 / A22 / A23。
- **选项**：在 CD 详情/唱片机旁补一条轻量信息条（曲名、进度、seek、静音、格式/采样率/位深）；或正式从 v1.0 移除。
- **建议**：至少补 seek + 当前曲目信息条；HiFi 信号展示是产品差异点，不应只剩数据层。
