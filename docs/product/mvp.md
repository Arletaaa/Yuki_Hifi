# Arlt HiFi Player v1.0 MVP 与验收标准

> 范围以 [ADR 003](../decisions/003-v1-scope.md) 为准。本文件的每条验收项都必须能被一条测试、一个截图或一次手测覆盖。

## 目标

形成一个可日常使用的本地 HiFi 桌面播放器闭环：选目录 → 扫描 → 收藏 → 在 3D 展厅中浏览 → 打开播放台 → 队列 → 信号信息 → 重启恢复，并可打包交付。

界面主体是「一条随曲库延伸的 CD 长廊」：曲库全部入场，收藏的 CD 有金边与边缘微光；镜头沿走廊移动，点开 CD 飞入播放台。[ADR 005](../decisions/005-scene-gallery.md)。

## 范围内

### 收藏（外观，不是内容）

- 任意曲目可收藏 / 取消收藏，状态持久化。
- 收藏**不决定**场景内容，只改变 CD 外观：金边 + 边缘微光 + 架位金色三角标记。
- 收藏状态在列表视图另有 ★ 与文本，不只靠颜色区分（色盲友好）。
- 设置项可关闭"场景高亮收藏"。

### 场景展厅（CD 长廊）

- 曲库全部按顺序陈列，每 24 首一个展示段（Bay），满 24 首向长廊末端生长一段。
- 只有 Bay 0 是"房间"形态（家具、窗、顶灯），Bay 1+ 是金属档案架长廊，远处接雾。
- 镜头沿走廊移动：拖拽平移、滚轮前后推进、双击回到当前曲目所在 Bay。
- 点击远处 CD / 搜索命中间：两段式移动（淡出 → 滑行入场），不长时间掠过。
- 虚拟化：常驻 Bay ≤ 5，封面纹理 LRU ≤ 48，曲库增长不线性吃显存。
- 写实光照与材质（PBR + 程序化环境光 + 接触阴影），不使用下载的 HDRI/贴图素材。
- 键盘与读屏可完成浏览与打开；WebGL 不可用时自动降级为列表视图。
- 详见 [场景展厅规格](../product/scene-gallery.md)。

### 播放台

- 悬浮 CD：随鼠标倾斜（±12°，带阻尼），播放时转动、暂停缓停。
- 盘面印当前封面；盘心孔、边缘衍射为程序化效果。
- 播放控制、进度、音量、信号信息悬浮在场景之上且不被遮挡。
- `Esc` / 返回按钮回到展厅。

### 库

- 通过主进程选择本地音乐文件夹，递归扫描 `flac`、`wav`、`mp3`、`m4a`、`ogg`。
- 列表视图：标题、艺术家、专辑、时长、格式、质量标记。
- 搜索（标题/艺术家/专辑，忽略大小写）、排序（标题/艺术家/时长/格式）、手动刷新。
- 状态：初始、扫描中、成功、空目录、失败（含原因与重试）。
- 记住上次目录，重启自动恢复曲库。

### 播放

- `HTMLAudioElement` 播放本地文件，媒体协议受控访问。
- 播放 / 暂停 / 上一首 / 下一首 / 拖动进度 / 音量 / 静音。
- 播放模式：顺序、单曲循环、随机。
- 播完自动下一首（顺序模式最后一首停止）。
- 错误态：格式不支持、文件不可读、自动播放被拦截，均有可恢复提示。

### 队列

- 队列与库解耦，默认等于库顺序。
- 队列页可跳到任意曲目、移除单曲、清空。
- 移除当前播放曲目时行为确定（跳到下一首，队列空则停止）。

### 元数据与封面

- 扫描时用 `music-metadata` 读取文件头：标题、艺术家、专辑、时长、采样率、位深、编码、内嵌封面。
- 标签缺失时回退到文件名推断，并在 UI 标注"文件名推断"。
- 封面写入 `userData/covers/` 缓存，列表行缩略图、播放栏唱片、壁纸取色共用同一张。
- 不做封面编辑、联网抓取、标签写回。

### HiFi 信息

- 展示当前曲目真实格式、编码、采样率、位深、时长（来自标签解析）。
- 读不到的字段显示 `—`，并说明原因（无标签 / 格式不支持）。
- 输出设备、独占模式显示"未接入 audio-core"，不显示 mock 数据。

### 设置

- 主题：深色 / 浅色。
- 背景壁纸：内置原创 SVG 夜景为默认；可选择本地图片，支持暗化与模糊，可恢复默认。
- 动效强度：关闭 / 标准 / 丰富（跟随系统 `prefers-reduced-motion`，系统偏好优先）。
- 关于：版本、数据存放位置、能力边界说明。

### 工程

- TypeScript strict，无未解释的 `any`。
- 渲染层只通过 preload API 访问系统能力。
- 单测覆盖 store（库/队列/模式/边界）、扫描器、格式化、播放错误映射。
- `pnpm build` 产出 `dist/` 与 `dist-electron/`，`pnpm start` 可运行。
- `electron-builder` 产出 Windows portable 包。

## 范围外

- Rust audio-core、真实解码、输出设备枚举、独占模式。
- 多目录、在线流媒体、账号、云同步、自动更新。
- 右侧舞台、角色舞台、Live2D、MV、动态视觉舞台、歌词滚动。
- Playwright 端到端（列入 backlog）。

## 非目标（明确不验收）

- 音频链路的比特精确性（无 audio-core 前不承诺）。
- 千级以上曲库的性能与增量索引。
- 安装包签名与自动更新。
- 场景的物理模拟（CD 不做刚体物理倾倒，用插值动画表达）。
- 写实渲染（不追求 PBR 材质与 HDRI 素材）。
