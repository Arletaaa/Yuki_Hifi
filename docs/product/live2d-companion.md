# Optional Desktop Companion Notes

## 目标

Arlt HiFi Player 当前不实现 Live2D、看板娘、角色舞台或动态视觉舞台。主播放器页面只保留音乐库、播放队列、播放栏和 HiFi 信息等核心播放界面。

本文仅记录未来“可选桌面伴随模式”的边界，避免它被误认为当前 UI 骨架要求。

## 页面原则

- 主播放器页面不保留右侧舞台、角色舞台或动态视觉舞台。
- 不使用占位角色区域来预留版面。
- 任何视觉反馈都应订阅播放器状态，而不是要求用户额外配置。
- 视觉反馈必须可关闭、轻量、不遮挡音乐库、播放控制、菜单或系统关键区域。

## 可选伴随模式

如果未来评估桌面伴随模式，应优先作为独立小窗口、可关闭浮层或系统托盘辅助能力，而不是主播放器页面的一部分。

需要先评估：

- Electron 小窗口或透明窗口策略。
- 性能和内存占用。
- 资源授权与分发方式。
- 与播放器状态、歌词状态和主题系统的接口边界。
- 关闭、隐藏、降低动效和无障碍设置。

## 当前阶段明确不做

- Live2D renderer 接入。
- 看板娘行为系统。
- 口型同步。
- 聊天气泡式歌词。
- 角色舞台。
- 动态视觉舞台。
- MV 或视频背景。

## 边界

不要在基础系统 UI 层中混入具体视觉引擎逻辑。未来任何 companion 或视觉反馈都应通过独立模块接入，并订阅播放器状态、歌词状态和主题状态。
